One line, one bug, one very relatable human glitch: a sneeze that loads to 99% and then cancels without explanation. The entry is a single changelog line in the terse register of a real release note, written by `main.py` to `entry.txt`.

> v2.1.5: fixed a bug where a sneeze loaded to 99% then cancelled without explanation.

## Run it

```sh
python3 main.py
```

The script writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). The line is 84 characters, inside the competition's 160-character cap.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
